the honest questions

does it sync automatically with goodreads or storygraph?
nope. there's no live api for either, this isn't a corner we cut, it just doesn't exist. you update it yourself in about ten seconds, which turns out to be pretty accurate anyway.
what happens if i lose the qr sticker?
hold the button on the back of the frame, it'll show its setup code on screen. you can also just type the code in by hand if the sticker's long gone.
why does the screen take so long to change?
it's e paper, the same family of screen as an e reader, no backlight, holds an image with almost no power. that's the tradeoff, it looks like paper but it isn't built for anything fast.
is my library data sold or shared?
no. what you set is stored to run the frame and that's it. terms and a plain language privacy note are linked below before you ever pay anything.
when does it ship?
first batch orders ship within of your preorder. you'll get an email with tracking the day it goes out.
what if i don't like it?
-day returns, no reasons needed. it also comes with a warranty against hardware defects. full details on the shipping and returns page.
does it need to stay plugged in?
yes, for now, this version lives near an outlet so it can check for updates quickly instead of sipping battery slowly. think of it more like a lamp than a phone.
