the honest questions

does it sync automatically with Goodreads or StoryGraph?
No. There's no live API for either. You update it yourself in about ten seconds, which turns out to be about as accurate anyway.
what happens if I lose the QR sticker?
Hold the button on the back of the frame and it'll show its setup code on screen. You can also type the code in by hand if the sticker's long gone.
why does the screen take so long to change?
It's e-paper, the same family of screen as an e-reader so no backlight, holds an image with almost no power. That's the tradeoff: it looks like paper, but it isn't built for anything fast.
is my library data sold or shared?
No. What you set is stored to run the frame, nothing else. Full terms and a plain-language privacy note are linked below before you ever put down a deposit.
